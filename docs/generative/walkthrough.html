概览

推荐系统需要从百万级候选 item 中快速挑选最相关的结果。本系统将每个 item 编码为固定长度的 token 路径（语义 ID / SID），组织成 Trie 树。在线推理时通过 Beam Search 在 Trie 上逐层搜索，每步只保留分数最高的 beam_width 条路径。

离线构建

Step 1: 排序 + diff-scan

np.lexsort 按字典序排列（本例已有序）。然后逐行比较相邻 item，找到首个不同的 depth。 该 depth 及更深层都标记为新节点 (is_new=True)，意味着需要在 Trie 中创建新 state。

Rowd0d1d2d3d4分叉说明
0 (a)TTTTT首行，全部新节点
1 (b)FFFFF与 row 0 完全相同
2 (c)FFTTTdepth 2 起新分支
3 (d)FTTTTdepth 1 起新分支
4 (e)FFFFT仅 depth 4 新叶子
5 (f)TTTTT首 token 变了，全部新
6 (g)FTTTTdepth 1 起新分支

Step 2: State ID 分配

L0 固定分配 V=2048 个槽位 (state = token + 1)；深层只为 is_new=True 的行分配新 ID，其余通过 np.maximum.accumulate 继承（共享前缀的 item 自动获得相同 state）。

L0 预分配 2048 个 state 是 Dense 层用空间换 O(1) 查表的代价 — State 3~2048 全为空。L1 从 State 2049 开始。

Step 3: CSR / Dense / Leaf 表

3a. packed_csr + csr_indptr — CSR 边表

CSR（Compressed Sparse Row）把所有边按父节点排成一个扁平数组 packed_csr， 再用指针数组 indptr 记录每个 state 的子节点在哪一段。 查询 state s 的子节点 = packed_csr[ indptr[s] : indptr[s+1] ]。

点击下方任意 state，查看 CSR 查表的完整过程:

packed_csr 数组 — 每组是一个 state 的所有出边，组内每格 = [token, child_state]:

← 点击上方的 State 按钮试试

关键观察：State 3~2048 （L0 的 2046 个空槽位）在 indptr 中全部指向同一位置 (4)。 它们不占 packed_csr 空间，但各占 indptr 的一个位置 — 这是 Dense 层预分配 V 个 state 的代价。 末尾追加 2048 行 [2048, 0] 作为 OOB 安全填充，防止越界读取。

3b. Dense 表 (前 d_dense=2 层)

为什么用 Dense 表？ 前几层用 token 值直接做数组下标，O(1) 查表，比 CSR 的 slice 更快。 代价是空间：[2048, 2048] 的数组中绝大多数位置是空的。 Beam Search 前 d_dense=2 步用 Dense 表，之后切换为 CSR。

下方是 dense_mask[2048, 2048] 的放大视图 (token 0~7 区域)，绿色格子 = 存在的前缀，点击可查看 state:

Dense vs CSR 对比 O(1) vs O(slice)
Beam 在 State 1 (token=0)，想查 token 2 的子节点:
Dense: dense_states[0, 2] → 2050 — 一次数组下标，完成
CSR: indptr[1]=0, indptr[2]=2 → packed_csr[0:2] → 遍历找 token=2 的行 → 2050

3c. Leaf → Item 映射

每个叶子关联若干 item。因为不同叶子关联的 item 数量不同，tensor 用 0 补齐成矩形 [6, 2]， leaf_item_valid 标记哪些是真实 item、哪些是 padding。

黄色卡片 = 多个 item 共享叶子（特殊情况）:

max_items_per_leaf = 2（因为 leaf 0 关联了 2 个 item）。 局部索引 = state_id - 2063 (leaf_start)。Phase 4 用 scatter_reduce(amax) 将 beam 分数写回 item 维度。

Phase 3: Beam Search (beam_width=3)

每步对 beam × children 所有候选做全局 topk。Step 0~1 用 Dense 表 O(1) 查询；Step 2~4 用 CSR。

→ 点击 Trie 的「Beam Search 动画」按钮可逐步查看搜索过程

Phase 4: Resolve Leaves

叶子 state 通过 leaf_item_ids 映射回 item index，用 scatter_reduce(amax) 聚合分数。 State 2063 同时映射到 item a 和 b（共享叶子），二者获得相同分数。
