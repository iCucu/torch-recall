torch-recall

基于 PyTorch 的召回框架。统一的 RecallOp 接口， 声明式 And / Or 组合，AOTInductor 导出 .pt2 模型包。

Python ≥ 3.10 PyTorch C++ 推理
01

架构

所有召回方法继承 RecallOp(nn.Module)，共享统一的 forward 签名。 通过 And（交集 / 分数求和）与 Or（并集 / 分数取 max）声明式组合为 Pipeline，编译导出为单一 .pt2 模型包。

class RecallOp(nn.Module):
  def forward(self, pred: Tensor[B,P], query: Tensor[B,D]) → Tensor[B,N]

示例：Or( And(Targeting, KNNcosine), And(Targeting, Generativebeam=10) ) → topk(50)

02

召回方法

Targeting 定向召回
布尔规则精确匹配，根据用户属性过滤 item。支持 == != > contains 等运算符。
端到端示例 →
KNN 近邻召回
向量相似度检索，brute-force matmul 计算内积、余弦或 L2 距离。
文档编写中
Generative 生成式召回
Trie 前缀树约束 Beam Search，纯 tensor 操作，兼容 torch.export。
设计文档 → 交互式示例 ★
03

声明式组合

通过 And（交集 / 分数求和）与 Or（并集 / 分数取 max）组合任意召回方法， 支持嵌套，编译为单一 .pt2 模型。

定向过滤 + 语义排序
And( Targeting, KNN)
多路向量检索取并集
Or( KNNcosine, KNNl2)
复杂嵌套 — 多路召回 + 生成式
Or( And(Targeting, KNNcosine), And(Targeting, Generative))
