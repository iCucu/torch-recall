torch-recall 文档中心

基于 PyTorch 的召回框架。每种召回方法实现为统一的 RecallOp（nn.Module）， 通过声明式组合（And / Or）灵活编排，经 AOTInductor 导出为单一 .pt2 模型包。

Python ≥ 3.10 PyTorch C++ 推理

架构概览

所有召回方法共享统一的 forward 签名，可任意组合：

召回方法

🎯
Targeting 定向召回
布尔规则匹配。根据用户属性评估每个 item 的定向规则，返回 0.0（匹配）或 -inf（不匹配）。 支持 == != > < contains 等运算符和 AND/OR/NOT 连接。
精确过滤 O(B×P×C)
→ 端到端示例
📐
KNN 近邻召回
向量相似度检索。将 item 和 query 映射为 embedding，通过 brute-force matmul 计算内积、余弦或 L2 相似度。
语义匹配 inner_product / cosine / l2
文档编写中
🌳
Generative 生成式召回
将每个 item 编码为固定长度的语义 ID 路径 (SID)，组织成 Trie 前缀树。在线推理时： (1) Targeting 过滤 → (2) Validity Propagation 自底向上剪枝 → (3) Decoder 自回归 Beam Search（Dense/CSR 混合查表） → (4) 叶子反解为 item 分数。 全流程纯 tensor 操作，兼容 torch.export。
自回归解码 Trie 约束 beam_width 可配 Dense + CSR 混合
→ 设计文档 → 交互式端到端示例 ★

声明式组合 Pipeline

通过 And（交集/分数求和）和 Or（并集/分数取 max）组合多种召回方法，编译为单一模型。

pred_satisfied [B, P] → And / Or → RecallOp × N → topk(K) → scores, indices [B, K]

组合示例

And(Targeting, KNN) ← 定向过滤 + KNN 排序 Or(KNN("cosine"), KNN("l2")) ← 多路 KNN 取并集 Or( ← 复杂嵌套 And(Targeting, KNN("cosine")), Generative(decoder, beam=10), )
