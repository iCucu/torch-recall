torch-recall

基于 PyTorch 的召回框架。统一的 RecallOp 接口，声明式组合，AOTInductor 导出。

Python ≥ 3.10 PyTorch C++ 推理
01

架构

所有召回方法继承 RecallOp(nn.Module)，共享同一 forward 签名，可通过 And / Or 任意组合并编译导出。

02

召回方法

Targeting 定向召回
布尔规则精确匹配，根据用户属性过滤 item。
端到端示例 →
KNN 近邻召回
向量相似度检索，支持内积、余弦、L2 距离。
文档编写中
Generative 生成式召回
Trie 前缀树约束 Beam Search，纯 tensor 操作，兼容 torch.export。
设计文档 → 交互式示例 ★
03

声明式组合

通过 And（交集）与 Or（并集）组合任意召回方法，编译为单一 .pt2 模型。

定向过滤 + 语义排序
And( Targeting, KNN)
多路向量检索
Or( KNNcosine, KNNl2)
复杂嵌套
Or( And(Targeting, KNN), Generative)
04

快速开始

# 环境准备 git clone git@github.com:iCucu/torch-recall.git && cd torch-recall uv venv --python 3.12 .venv && source .venv/bin/activate uv pip install torch pytest jieba uv pip install -e "index[dev]" # 运行测试 pytest index/tests/ -v # 运行示例 PYTHONPATH=index python examples/05_generative_recall.py
